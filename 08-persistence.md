# Three Persistence Modes
[Home](index.html) · [Previous](07-topologies.md) · [Next](09-atlas.md)

Persistence Mode asks **how the achieved result remains available as achieved**.

| Mode | Mode of achieved availability |
|---|---|
| **Standing** | The achieved determination stands available as itself. |
| **Bearing** | The achievement holds through a constitutive relation, contrast, source, condition or support. |
| **Efficacy** | The achievement remains as an operative capacity, effect, rule or changed continuation. |

These are not successive phases. A standing determination may be relational; an efficacy may prevent an action rather than produce one.

**Distinguish:** persistence of a completed result is not the same question as transmission of an intelligible structure between speech, writing, memory or other carriers.
